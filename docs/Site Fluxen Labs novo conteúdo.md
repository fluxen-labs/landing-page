# Site Fluxen Labs: novo conteúdo

Oct 9, 2026 · @Marcelo

## O que sai do site atual

O site atual fala com engenheiros, não com donos de empresa, e sustenta números que nenhum cliente comprovou. O novo conteúdo segue a mesma linha dos posts do Instagram: frases curtas, a dor antes da solução e nenhum dado sem lastro.

| Sai | Por quê |
| --- | --- |
| Métricas "99.9% uptime", "<100ms latência", "24/7 monitorado" | Não descrevem nenhum projeto real e são o clichê número um de landing page de IA |
| Os dois "cenários ilustrativos" com faturamento, equipe e pedidos por mês | Números inventados lidos como caso real; quando houver caso autorizado, ele entra no lugar |
| Jargão como "modelagem orientada a evento", "camada intermediária validada", "NLP", "motor de orquestração" | O cliente não entende e não busca esses termos |
| "Nossos diferenciais" e "compromisso com excelência e resultados comprovados" | Frase genérica sem prova |
| Frases de efeito repetidas ("Sem promessa vaga. Sem buzzword.", "Não otimizamos tarefas isoladas") | Dizem que não há buzzword usando buzzword |
| Lista "Para quem é" com 7 itens que misturam perfil do cliente e característica da solução | Vira 3 sinais claros, iguais aos do post |

**Fica:** o link de WhatsApp do botão de diagnóstico, o e-mail de contato e o LinkedIn.

## Estrutura da página

Uma página só, com 10 seções na mesma ordem lógica da grade do Instagram: o que é, se é para mim, o que dá para fazer, como e como começar.

1. Topo (o que a Fluxen faz)
2. Para quem é
3. O que dá para automatizar
4. Como trabalhamos
5. Sistemas sob medida
6. IA aplicada
7. Diagnóstico técnico
8. Quem lidera
9. Perguntas frequentes
10. Fechamento e rodapé

**Menu:** Para quem é · Como trabalhamos · Diagnóstico · Contato

**Botão fixo no menu:** Agendar diagnóstico (abre o WhatsApp com a mensagem pronta, mesmo link de hoje).

Todo botão de chamada leva ao mesmo link de WhatsApp. Um caminho só, sem formulário.

## Conteúdo: seções 1 a 3

Cada seção tem um rótulo curto (o mesmo papel do badge dos posts), um título e no máximo uma frase de apoio.

### 1. Topo

- **Rótulo:** AUTOMAÇÃO E SISTEMAS PARA EMPRESAS
- **Título:** Sua empresa faz à mão o que um sistema poderia fazer sozinho?
- **Texto:** A Fluxen Labs identifica o que vale automatizar na sua operação e constrói a solução, integrada aos sistemas que você já usa.
- **Botão principal:** Agendar diagnóstico técnico
- **Botão secundário:** Ver como trabalhamos (rola até a seção 4)
- **Linha abaixo dos botões:** Diagnóstico técnico sem compromisso.

### 2. Para quem é

- **Rótulo:** PARA QUEM É
- **Título:** Para empresas que cresceram mais rápido que a própria estrutura

| Sinal | Descrição |
| --- | --- |
| Pedidos digitados à mão | Informação copiada do WhatsApp para a planilha, e da planilha para o sistema. |
| Operação que depende de uma pessoa | Se ela falta, o processo para. |
| Sistema pago, pouco usado | ERP que só emite nota, enquanto o resto roda em planilha. |

- **Fecho:** Reconheceu algum? É por aí que a gente começa.

### 3. O que dá para automatizar

- **Rótulo:** O QUE AUTOMATIZAR
- **Título:** Rotinas que um sistema pode assumir

| Exemplo | Descrição |
| --- | --- |
| Pedidos do e-commerce no sistema de gestão | Sem ninguém digitar pedido por pedido. |
| Cobranças e lembretes de pagamento | Enviados no momento certo, sem depender de alguém lembrar. |
| Relatórios que se montam sozinhos | Com os dados que hoje alguém copia à mão toda semana. |
| Aprovações em um fluxo único | No lugar de e-mails e planilhas circulando entre áreas. |
| Sistemas que passam a conversar | O que é lançado em um sistema chega aos outros, sem retrabalho. |

São exemplos de tipos de rotina, não casos de clientes; o site não deve apresentá-los como projetos entregues.

## Conteúdo: seções 7 a 10 e SEO

A reta final da página leva para um único passo, o diagnóstico técnico, e o rodapé só confirma quem está por trás.

### 7. Diagnóstico técnico

- **Rótulo:** DIAGNÓSTICO TÉCNICO

## Como levar para o Claude Code

Separe conteúdo de layout: o texto entra como arquivo no repositório, e o Claude Code monta a página a partir dele sem reescrever nada.

1. Exporte este documento em Markdown e salve no projeto como `docs/conteudo-site.md`.
2. Separe 2 ou 3 referências da refero.design e salve os prints em `docs/referencias/`.
3. Rode o Claude Code na raiz do projeto com um pedido neste formato:

```
Reconstrua a home seguindo docs/conteudo-site.md.
Use os textos exatamente como estão, sem acrescentar seções, métricas ou frases.
Remova tudo que o documento lista em "O que sai do site atual".
Use as imagens em docs/referencias/ só como referência de estrutura e ritmo, não de cores.
Cores: fundo #1e293b, texto #f1f5f9, destaque #f9f0de.
Nada de gradiente, brilho, vidro fosco ou ícone genérico.
Mantenha o link de WhatsApp atual em todos os botões de diagnóstico.
```

4. Teste antes de publicar: abra a prévia da Vercel no celular e confira se todos os botões abrem o WhatsApp com a mensagem pronta.

**Cuidado com o "descolado":** layout muito ousado pode brigar com o posicionamento premium e com a grade do Instagram que você acabou de montar. A forma mais segura de tirar a cara de landing page de IA é usar a mesma identidade dos posts (azul-ardósia, creme, diagramas de nós, muito espaço vazio), e não um estilo novo. Assim quem vem do Instagram reconhece a marca no site.
